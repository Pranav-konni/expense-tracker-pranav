Here I created a simple standard expense tracking app for personal using.

Steps of Expenses Tracker App
=================================

Add income
---------------------------------
1. Don't need to login.
2. User have to select income or expense.
3. Enter the description salary or any descriptions.
4. Must enter the amount.
5. Choose category
6. Click Add button


Add expenses
---------------------------------
1. Enter the description like electricity bill or rents etc
2. Enter the amount.
3. Choose the category.
4. Click Add button


In chart we can see the expense based on categories and come to right screen we can see the transaction history both income and salary. We can also choose which one should have shows in transaction section.
And top side we can see the Total income, Total Expenses, Available balances and Number of transanctions.
